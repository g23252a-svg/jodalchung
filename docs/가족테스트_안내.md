# 1주차 가족 테스트 안내 (10/19~25)

목적: 추천안 「살펴봇 공정심사실」로 계속 갈지, 대안 「꾹탁 비축창고」로 바꿀지 정한다.

## 준비
- PC에서 `index.html` 더블클릭 (Chrome/Edge). 휴대폰 테스트는 아직 하지 않는다.
- 테스트하는 사람에게 **설명을 하지 않는다.** "이거 한번 해 봐"만 말하고 지켜본다.
- 가능하면 3명: 초등학생 1, 20~50대 1, 60대 이상 1.

## 지켜볼 것 (옆에서 메모)
| 체크 | 기준 |
|---|---|
| 10초 이해 | 첫 카드가 나오고 10초 안에 스스로 밀거나 버튼을 눌렀나 |
| 숨은 정보 | 점선 칸을 누를 줄 알았나 (연습 3번째 카드) |
| 규칙 변경 | 2단계 "우려 품목" 안내 뒤 '입찰보증금' 칸을 보고 판정했나 (우려 품목이라고 무조건 ←로 보내지 않았나) |
| 살펴봇 의심 | 살펴봇이 틀린 말을 할 때 따르지 않은 적이 있나 (결과 화면 '버릇 잡기' 숫자) |
| 막힌 곳 | 멈추거나 "이거 뭐야?"라고 물은 곳 |
| 시간 | 결과 화면까지 걸린 시간 (3~4분 목표) |

결과 화면 아래 회색 칸 **"테스트 기록"** 에 첫 정답까지 걸린 시간, 단계별 정답 수가 자동으로 나온다. 사진을 찍어 두면 된다.

## 끝나고 물어볼 것 (두 개만)
1. 처음에 무엇을 해야 하는지 금방 알았어요? (예/아니오)
2. 한 판 더 해 볼래요? (예/아니오)

## 판정 기준
- 3명 중 2명 이상이 **두 질문 모두 "예"** → 살펴봇으로 확정, 2주차 진행
- 아니면 → 무엇이 막혔는지 적어서 공유. 고쳐서 다시 해 보거나 대안으로 전환

## 주의
- 현재 버전은 **사실 검수 전 시제품**이다. 게임 속 정책 문구를 그대로 신청서에 옮기지 않는다.
- 녹화나 공개 업로드는 하지 않는다 (발표일 12/9 전 공개 배포는 제외 사유가 될 수 있음).
