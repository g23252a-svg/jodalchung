# 1주차 가족 테스트 안내 (10/19~25)

목적: 두 후보 중 제출작 하나를 고른다.
- A. 「살펴봇 공정심사실」 v0.4 (`game/index.html`): 입찰 서류 카드를 밀어서 판정
- B. 「혁신조달 매칭 본부」 v0.2 (`match/index.html`): 기관 조건과 제품 사양을 비교해 짝짓기

## 준비
- PC에서 `index.html` 더블클릭 (Chrome/Edge). 휴대폰 테스트는 아직 하지 않는다.
- 테스트하는 사람에게 **설명을 하지 않는다.** "이거 한번 해 봐"만 말하고 지켜본다.
- 가능하면 3명: 초등학생 1, 20~50대 1, 60대 이상 1.
- 한 사람이 **두 게임을 모두** 한다. 순서는 사람마다 바꾼다(1번 사람 A→B, 2번 사람 B→A, 3번 사람 A→B).
- 살펴봇은 60대 이상·초등학생에게 먼저 **쉬운 모드**로 하게 한다.

## 지켜볼 것 (옆에서 메모)

### A. 살펴봇 공정심사실
| 체크 | 기준 |
|---|---|
| 10초 이해 | 첫 카드가 나오고 10초 안에 스스로 밀거나 버튼을 눌렀나 |
| 숨은 정보 | 점선 칸을 누를 줄 알았나 (연습 3번째 카드) |
| 조사권 | 조사권이 모자라 아쉬워했나, 아무 칸이나 다 열었나 |
| 규칙 변경 | 2단계 "우려 품목" 안내 뒤 '입찰보증금' 칸을 보고 판정했나 (우려 품목이라고 무조건 ←로 보내지 않았나) |
| 살펴봇 의심 | 살펴봇이 틀린 말을 할 때 따르지 않은 적이 있나 (결과 화면 '버릇 잡기' 숫자) |
| 막힌 곳 | 멈추거나 "이거 뭐야?"라고 물은 곳 |
| 시간 | 결과 화면까지 걸린 시간 (3~4분 목표) |

결과 화면 아래 회색 칸 **"테스트 기록"** 에 첫 정답까지 걸린 시간, 단계별 정답 수가 자동으로 나온다. 사진을 찍어 두면 된다.

### B. 혁신조달 매칭 본부
| 체크 | 기준 |
|---|---|
| 10초 이해 | 첫 신청서에서 10초 안에 왼쪽 조건을 눌렀나 (버튼에 ①②③ 안내가 나옴) |
| 숫자 비교 | 노랗게 빛나는 칸의 숫자를 보고 골랐나 (예: 교실 60㎡ ↔ 정화 면적 5㎡) |
| 살펴봇 의심 | 살펴봇이 틀린 추천을 할 때 따르지 않은 적이 있나 (결과 화면 '살펴봇 추천 바로잡기' 숫자) |
| 실패 뒤 | 실패한 카드의 X 표시를 보고 이유를 이해했나 |
| 막힌 곳 | 멈추거나 "이거 뭐야?"라고 물은 곳 |
| 시간 | 결과 화면까지 걸린 시간 (3분 안팎 목표) |

결과 화면에 '한 번에 해결 / 살펴봇 추천 바로잡기 / 조건을 모두 비교한 신청' 숫자가 나온다. 사진을 찍어 두면 된다.

## 끝나고 물어볼 것 (게임마다 두 개, 마지막에 하나)
1. 처음에 무엇을 해야 하는지 금방 알았어요? (예/아니오)
2. 한 판 더 해 볼래요? (예/아니오)
3. (두 게임을 다 한 뒤) 둘 중 하나만 다시 한다면 어느 쪽이에요?

## 판정 기준
- 게임마다 3명 중 몇 명이 **1·2번 모두 "예"** 인지 센다.
- 더 많은 쪽을 제출작으로 정한다. 같으면 3번 질문에서 더 많이 고른 쪽.
- 둘 다 2명 미만이면 → 무엇이 막혔는지 적어서 공유. 고쳐서 다시 해 본다.

## 주의
- 현재 버전은 **사실 검수 전 시제품**이다. 게임 속 정책 문구를 그대로 신청서에 옮기지 않는다.
- 녹화나 공개 업로드는 하지 않는다 (발표일 12/9 전 공개 배포는 제외 사유가 될 수 있음).
