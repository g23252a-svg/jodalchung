## 4. 놓치기 쉬운 요건과 기술 함정

### 4-1. 실행파일(ZIP)
심사위원은 ZIP을 풀고 `index.html`을 더블클릭해 열 가능성이 큽니다. 이때 생기는 문제를 실측했습니다(Chrome, 2026-10-18).

- **HTML 파일 하나에 모든 것을 넣어야 합니다.** JS, CSS, 이미지, 사운드, 폰트, 데이터 전부입니다.
  - 외부 module 스크립트, fetch 요청, 로컬 JSON 읽기는 막혀서 실패합니다.
  - 파일 이미지를 캔버스에 그리면 보안 오류가 납니다.
  - 인터넷 없이 실행될 수 있으니 CDN이나 구글폰트에 기대면 안 됩니다.
- **별도 `.js` 파일과 `.exe`는 넣지 마세요.**
  - Gmail은 `.js`가 ZIP 안에 들어 있어도 차단합니다.
  - Daum은 `.exe`와 `.js`를 주고받지 못합니다.
  - 서명 없는 exe는 SmartScreen 경고나 백신 오탐에 걸릴 위험도 있습니다.
- **ZIP 구성:** `index.html`, `README.txt`(실행 방법), `CREDITS.txt`(AI 도구와 출처), `licenses/`(폰트 라이선스 원문).
  - 파일명은 모두 영문으로 하고, 폴더는 0~1단계로 얕게 둡니다.
  - Windows 경로 길이 제한 때문에, 실측에서 265자 경로는 열리지 않았습니다.
- **소리는 첫 클릭 뒤에만 납니다.** 시작 화면에 "시작(소리 켜기)" 버튼을 둡니다.
- **localStorage는 저장이 안 돼도 게임이 진행되게 만듭니다.** try/catch로 감쌉니다.
- **압축을 풀지 않고 ZIP 미리보기에서 바로 연 경우를 대비해** "압축을 풀고 실행하세요" 안내를 띄웁니다.

### 4-2. 시연영상
- **화면 비율:** 1920×1080 가로(16:9)로 만듭니다. 세로 영상은 규격 미준수로 볼 여지가 있습니다.
- **녹화:** OBS로 1920×1080, 30~60fps로 녹화합니다.
- **최종 출력:** H.264 약 2.5Mbps로 내보내면 60초에 약 19MB입니다.
- **자막:** 한글 자막을 필수로 넣습니다. 소리 없이 보는 경우를 대비해서입니다.
- **편집 도구:** Clipchamp 무료판이나 DaVinci Resolve 무료판을 권합니다.
  - CapCut은 약관상 상업적 이용과 충돌할 수 있습니다. 쓰더라도 앱에 들어 있는 음악·템플릿·스티커는 쓰지 마세요.

> - **랜덤 카드**: 44장 중에서 판마다 다르게 뽑습니다. 결과 화면의 심사 번호를 `#s번호`로 붙이면 같은 카드로 다시 할 수 있습니다.
> - **쉬운 모드(대중성)**: 숨은 칸을 마음껏 열 수 있고 3단계까지만 합니다. 어려운 말 아래에 '쉬운 말' 한 줄을 붙였습니다.
> - 살펴봇 버릇 도감은 이 브라우저에만 저장됩니다. 자동 점검 때는 저장하지 않습니다.

### 8-1. 핵심 메시지
"AI는 근거를, 결정은 사람이. 공정은 의심과 기회의 균형."

- 플레이어는 가상의 '공정조달 심사실'에 새로 온 심사관입니다.
- 짝꿍은 돋보기 머리를 한 AI 조수 로봇 '살펴봇'입니다.
  - 말버릇: "제가 찾은 근거는 여기! 결정은 심사관님이"
- 살펴봇은 조달청의 실제 시스템이 아닌 **가상 캐릭터**라고 시작 화면과 도움말에 밝힙니다.
  - 조달청의 'AI 기반 기술평가 지원시스템'(2026-08 실증 착수, 대상은 우수제품 지정심사와 협상계약 제안서 평가)의 원칙만 빌려온 설정입니다.
  - 그래야 살펴봇의 오판이 실제 시스템의 결함으로 읽히지 않습니다.

### 8-2. 핵심 플레이(카드 1장에 약 5~6초. 시간 표기는 하나로 통일)
1. **카드가 뜹니다.** 가상 기업의 **물품 구매** 입찰 카드입니다. 기업 유형 배지, 품목, 서류 칸 3개가 있습니다.
2. **살펴봇이 근거를 짚습니다.** 근거 위치에 형광펜을 긋고 '참고용' 말풍선을 띄웁니다.
   - 판정에 꼭 필요한 정보 하나는 **'근거 탭'을 해야만 보입니다.** 예: 서류 날짜, 품목이 우려 품목인지 여부.
   - 이렇게 해야 AI 근거를 확인하는 행동이 실제 결정에 쓰입니다. 원안대로면 "살펴봇을 무시하고 배지만 보는" 전략이 가장 유리해집니다.
3. **의심 카드에서는 '두 칸 잇기'를 합니다.** 서류 칸(예: 주소)과 현장 그림(예: 간판·건물)을 손가락으로 이어 대조합니다. 무언가를 발견하는 손맛을 주는 장치입니다.
4. **판정합니다.**
   - 오른쪽: 심사 진행
   - 왼쪽: 현장 확인 요청(2단계부터는 '입찰보증금 요구 + 현장 확인')
   - 위쪽: 혁신 패스트트랙(3단계)
   - 우대 가점은 따로 탭하지 않고 판정 방향에 합칩니다.
   - 화면 양옆에 큰 버튼도 둡니다. 스와이프에 익숙하지 않은 분을 위해서입니다.
5. **피드백을 줍니다.**
   - 정답이면 0.5초짜리 짧은 알림만 띄웁니다.
   - 오답이거나 규칙이 바뀔 때만 멈추고, 근거 규칙·시행일·출처를 한 줄로 보여 줍니다.
   - 살펴봇의 오판을 바로잡으면 '검증 보너스'를 줍니다.
   - 살펴봇의 오판에는 **배울 수 있는 패턴**이 있습니다. 예: 지난 단계의 규칙을 그대로 적용하는 실수.

## 9. 대안 상세: 「꾹탁 비축창고」(검증 반영 수정판)

**핵심:** 원버튼으로 물가선을 초록 안정 띠 안에 지키는 아케이드 게임입니다. 소재는 조달청 비축사업입니다.

**조작을 고칩니다.**
- 길게 누르기(꾹) = 매입. 값이 쌀 때 효율이 높습니다.
- 짧게 탭(톡) = 방출. '창고 문이 열리는' 큰 한 방 연출을 줍니다.
- 손을 뗌 = 시장 흐름대로 표류(중립 상태).
- 원안은 손을 떼면 방출되는 구조라 "평소에 채워 둔다"는 메시지와 어긋났습니다.

**정책 표현을 고칩니다.**
- **비축의 원리는 공식 설명대로:** "가격이 안정됐을 때 사서 비축하고, 값이 오르거나 수급이 어려울 때 방출한다". "폭락 때 사서 가격을 받친다"는 공식 설명에 없으므로 뺍니다.
- **민관공동비축:** 민간이 산 원자재를 조달청 비축기지에 보관·관리하는 사업입니다(조달사업법 제32조). 그래서 '민간 물량 입고' 아이템으로 만듭니다. 원안의 '창고 용량 +1칸'은 틀린 매핑입니다.
- **'61일분':** 알루미늄·구리 등 핵심 원자재의 목표입니다. 스테이지 1·2에만 씁니다.
- **요소:** '경제안보품목 요소'로 표기합니다.
- **AI 공급망관리, 5개 권역 재편:** '추진 중'으로 씁니다.

**재미를 보강합니다.**
- 안정 띠가 움직이거나 좁아지는 구간을 넣습니다.
- 충격이 연달아 오는 구간을 넣습니다.
- 엔딩 반전 카드: "방금 손으로 반복한 순서(징후 → 대체 공급선 → 선적 앞당기기 → 비축)는 2026 한국정책대상 대상을 받은 실제 조달청 대응 순서"
- 시연영상 훅 자막에는 '2021년 요소수 품절'처럼 연도를 넣어, 2026년 사건과 시점이 섞이지 않게 합니다.

**위험:** 원버튼 장르(헬리콥터 게임, Geometry Dash의 Wave 모드)에 비축 소재만 입힌 것으로 보일 수 있습니다. 1주차에 "다시 하고 싶은가"를 측정해서 재미가 없으면 바로 접습니다.

## 9-A. 새 후보: 「혁신조달 매칭 본부」(프로토타입 v0.2, 2026-10-19)

대중성(모든 연령층) 우려를 줄이려고 만든 두 번째 후보입니다. 파일은 `match/index.html` 하나이며, 인터넷 없이 더블클릭으로 실행됩니다.

- **한 줄 소개**: 매칭 담당관이 되어 동네 기관(학교·소방서·구청·복지관·수영장·보건소·도서관)의 조건과 가상 혁신제품의 사양을 비교해 짝지어 줍니다. 짝지으면 시범사용을 거쳐 성공판정이 나고, 동네 그림이 바뀝니다.
- **핵심 조작**: 조건을 누르면 세 제품에서 비교할 칸이 노랗게 빛납니다. 숫자와 상황을 비교해 고른 뒤 [매칭하기]를 누릅니다. 끌어다 놓기와 키보드 1·2·3 + Enter도 됩니다.
- **AI와 사람**: 살펴봇은 매 신청서마다 추천을 하지만, 판마다 무작위로 3곳은 틀린 추천을 합니다(버릇: '성능만 보기', '값만 보기'). 틀린 추천을 바로잡으면 +50점입니다. 그래서 한 판 더 하면 다른 게임이 됩니다.
- **실제 제도와 이어지는 점**: 시범구매 단계(수요조사 → 매칭·계약 → 테스트 → 성공판정), 성공판정 제품의 우수조달물품 심사 특례, 혁신제품 3년 수의계약, 2026년 1차 시범구매 133개 제품·약 323억 원.
- **역할 안내**: 실제로는 수요기관이 혁신장터에서 혁신제품을 골라 시범사용을 신청하고, 조달청이 기관과 기업을 이어 계약합니다. 게임은 이 과정을 조건 맞추기로 줄였다고 도움말과 결과 화면에 적었습니다.
