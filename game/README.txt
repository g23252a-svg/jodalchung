살펴봇 공정심사실 (프로토타입 v0.4)
=====================================

실행 방법
1. 압축을 푼다. (압축 파일 미리보기에서 바로 열지 말 것)
2. index.html 을 더블클릭한다. Chrome 또는 Edge 권장.
3. "소리 켜고 시작", "소리 없이 시작", "쉬운 모드" 중 하나를 누른다.
   - 쉬운 모드: 숨은 칸을 마음껏 열 수 있고, 실전 단계 없이 3단계까지 진행

조작
- 카드를 왼쪽/오른쪽으로 밀기 (3단계와 실전은 위쪽도) 또는 화면 아래 큰 버튼
- 키보드: 왼쪽/오른쪽/위쪽 방향키, 숫자 1·2 = 숨은 칸 열기, 스페이스바 = 다음 숨은 칸 열기, Enter = 다음, Esc = 도움말 닫기
- 점선 칸(숨은 정보)은 눌러서 확인. 단계마다 조사권 3장(실전 2장)

판마다 카드가 달라집니다. 결과 화면의 '심사 번호'를 주소 끝에 #s번호 로 붙이면 같은 카드로 다시 할 수 있습니다(예: index.html#s1234).

인터넷 연결 없이 동작합니다. 외부 파일·외부 서버를 쓰지 않습니다.
게임 속 기업·인물·단서·동네 소식은 모두 가상입니다. 살펴봇은 조달청 실제 시스템이 아닌 가상 캐릭터이며, 대사는 미리 짠 시나리오입니다.

점검용 주소 끝에 붙이는 옵션(개발용)
- #demo     : 자동 시연(영상 녹화용, 천천히)
- #autotest : 자동 점검(빠르게 끝까지)
