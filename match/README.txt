혁신조달 매칭 본부 (프로토타입 v0.2)
=====================================

실행 방법
1. 압축을 푼다. (압축 파일 미리보기에서 바로 열지 말 것)
2. index.html 을 더블클릭한다. Chrome 또는 Edge 권장.
3. "소리 켜고 시작" 또는 "소리 없이 시작"을 누른다. (한 판 3분 안팎)

하는 법
- 왼쪽 신청서의 조건을 누르면, 세 제품에서 비교할 칸이 노랗게 빛난다.
- 숫자와 상황을 비교해 모든 조건에 맞는 제품을 고르고 [매칭하기]를 누른다.
- 제품 카드를 신청서로 끌어다 놓아도 골라진다.
- 키보드: 1·2·3 = 제품 고르기, Enter = 매칭하기, Esc = 도움말 닫기

살펴봇의 추천은 미리 짠 시나리오이며, 판마다 3곳은 일부러 틀린다. 어느 신청서에서 틀릴지는 판마다 바뀐다.
두 번째 판부터는 연습 신청서(○○초등학교)를 건너뛴다.

인터넷 연결 없이 동작합니다. 외부 파일·외부 서버를 쓰지 않습니다.
게임 속 기관·기업·제품·사연은 모두 가상입니다. 살펴봇은 조달청 실제 시스템이 아닌 가상 캐릭터입니다.

점검용 주소 끝에 붙이는 옵션(개발용)
- #demo     : 자동 시연(영상 녹화용, 천천히)
- #autotest : 자동 점검(빠르게 끝까지, 기록은 저장하지 않음)
