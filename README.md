# 살펴봇 공정심사실

「2026 조달청 AI 게임·콘텐츠 공모전」 AI 게임 부문 출품 준비 저장소입니다. (마감 2026-11-22)

> AI는 근거를, 결정은 내가! — AI 조수 '살펴봇'이 짚어 주는 근거를 직접 확인하며, 바뀌는 조달 규칙에 맞춰 가상 기업 카드를 판정하는 3~4분짜리 웹 게임.

## 실행
1. `game/index.html` 을 더블클릭 (Chrome/Edge 권장, 인터넷 연결 불필요)
2. "소리 켜고 시작" 또는 "소리 없이 시작"
3. 주소 끝에 `#demo` 를 붙이면 자동 시연, `#autotest` 는 빠른 자동 점검

온라인 테스트 플레이: 비공개 Claude 아티팩트 https://claude.ai/artifact/XepjZpPusscYq6tzvtep38 (저장소 주인 계정으로 claude.ai에 로그인해야 열림)
