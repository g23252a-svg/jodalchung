## 실행
1. `game/index.html` 또는 `match/index.html` 을 더블클릭 (Chrome/Edge 권장, 인터넷 연결 불필요)
2. "소리 켜고 시작" 또는 "소리 없이 시작" (살펴봇은 "쉬운 모드"도 있음)
3. 주소 끝에 `#demo` 를 붙이면 자동 시연, `#autotest` 는 빠른 자동 점검

## 현재 상태 (2026-10-19)

### 살펴봇 공정심사실 v0.4
- 연습 + 1~3단계 + 4단계 실전(살펴봇 없이 혼자 판정) + 결과 화면(결과 카드 1080×1350 PNG)
- 카드 44장 중에서 판마다 다르게 뽑음. 결과 화면의 심사 번호를 주소 끝에 `#s번호` 로 붙이면 같은 카드로 다시 할 수 있음
- 조사권: 숨은 칸은 단계마다 3장(실전 2장)만 열 수 있음. 남은 조사권은 점수로 바뀜
- 판정마다 '세금 낭비·기회 손실·지연' 게이지와 다음 날 동네 소식으로 결과를 보여 줌
- 쉬운 모드: 숨은 칸을 마음껏 열 수 있고 3단계까지만 진행. 어려운 말에는 '쉬운 말' 한 줄
- 반영한 정책(조달청 보도자료 기준): 무분별입찰 우려 품목 입찰보증금(2026.8.3), 직권조사(2026.9.11), 데이터 선별 의심업체 입찰보증금(2026.11.1), 혁신제품·우수조달물품 수의계약
- 확인: 브라우저 자동 점검 오류 0건. 전략 시뮬레이션에서 '필요한 칸만 열기'가 가장 높은 점수

### 혁신조달 매칭 본부 v0.2
- 연습 신청서 1개 + 신청서 6개(소방서·구청·복지관·수영장·보건소·도서관), 결과 화면에 바뀐 동네 지도
- 조건을 누르면 세 제품에서 비교할 칸이 빛남. 숫자와 상황을 비교해 골라야 풀림
- 살펴봇은 판마다 무작위로 3곳에서 틀린 추천을 함(버릇: '성능만 보기', '값만 보기'). 바로잡으면 +50점
- 반영한 제도: 혁신제품 시범구매 단계(수요조사 → 매칭·계약 → 테스트 → 성공판정), 성공판정 제품의 우수조달물품 심사 특례, 혁신제품 3년 수의계약
- 확인: 브라우저 자동 점검·사람처럼 하는 점검 오류 0건, 7개 신청서 모두 글자 넘침 없음
